# Joseph Aguilar-Bohorquez

Source for [Joseph Aguilar-Bohorquez's academic website](https://josephaguilarbohorquez.github.io).

The site is a static Next.js export published with GitHub Pages. Updates pushed to
`main` are built and deployed automatically.

## Common updates

- Replace `public/files/Joseph_Aguilar-Bohorquez_CV.pdf` to update the CV without
  changing its public URL.
- Replace
  `public/files/Joseph_Aguilar-Bohorquez_Latest_Presentation_Slides.pdf` to update
  the presentation slides without changing their public URL.
- Replace `public/images/joseph-aguilar-bohorquez.webp` to update the portrait.
- Edit `app/page.tsx` for content changes and `app/globals.css` for design changes.

## Local preview

Requires Node.js 22 or later.

```bash
npm install
npm run dev
```
